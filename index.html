Dugba Privacy Policy

Last updated: October 1, 2026

Dugba is a video game emulator for Android. This Privacy Policy explains how Dugba handles user information.

Information Collection

Dugba does not collect, store, transmit, or share personal information.

Game files, save data, save states, settings, and other emulator data are stored locally on the user's device. Dugba does not upload these files or data to the developer or to external servers.

File Access

Dugba may access files or folders selected by the user in order to load games and manage related game data. This access is used only to provide the app's functionality.

Third Parties

Dugba does not sell or share personal information with third parties.

Data Retention and Deletion

Because Dugba does not collect personal information on external servers, the developer does not retain personal user data. Locally stored app data can be removed by deleting it through the app, clearing the app's data, or uninstalling the app, as applicable.

Security

Dugba is designed to keep emulator data locally on the user's device unless the user explicitly uses a feature that transfers data elsewhere.

Changes to This Privacy Policy

This Privacy Policy may be updated if Dugba's features or data practices change. Updates will be posted on this page.
